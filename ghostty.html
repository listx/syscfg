Ghostty

Ghostty is our terminal. It replaced WezTerm in November 2026, and much of this configuration carries settings over from our WezTerm configuration, which is in the Git history. We install it with Nix on both NixOS and Mac. Its configuration is a flat list of key = value lines.

1.1 Option as Alt

By default, Ghostty on Mac treats Option the way macOS does: as a key for typing accented and other special characters. Then a chord like C-M-S-e (our tmux binding to split a pane) reaches tmux as some special character instead of a Meta chord, and none of our C-M- tmux bindings, or M- bindings anywhere else, work. WezTerm didn't have this problem because it treats the left Option key as Alt by default.

So treat the left Option key as Alt too. The right Option key still types special characters, for the rare times we want them.

1.4 Window

Open windows at the same size as WezTerm's, in cells, and with the same padding: a little on the left, so that text doesn't touch the window's edge, and none elsewhere. window-padding-x takes the left and right padding as a pair.

window-padding-y = 0

On Linux, Ghostty draws its own GTK title bar, with a menu and tab buttons, across the top of every window. Under xmonad this is just wasted space, because xmonad manages the windows and we keep tabs in tmux, which is also why we disabled WezTerm's tab bar. So turn it off. We use gtk-titlebar rather than window-decoration = none, because gtk-titlebar does nothing on Mac, where window-decoration = none would also remove the window's native border and rounded corners.

1.5 Colors

Use our PastelDark theme, the same colors as in WezTerm. The theme has to be in the config, not just applied by the shell, because Zsh assumes that the terminal starts out with PastelDark (it sets TERM_COLOR_THEME to it without sending any colors), so that color_cycle knows where to start.

As in WezTerm, bright black (palette entry 8) is #99999f instead of the theme's #343c48. The theme's value is the background color, so programs that draw text in bright black (such as jj) would leave what look like empty spots.

The selection colors also come from WezTerm, because the theme doesn't define any.

1.6 Closing windows

By default, Ghostty asks for confirmation before closing a window (or tab or split) whose shell is running another program. Our shell replaces itself with tmux, so every window counts as busy and Ghostty asks every time. But closing the window only detaches from tmux, and the session lives on, so nothing is lost and the question is just noise. So close without asking.

1.7 Clipboard notifications

By default, Ghostty shows a "Copied to clipboard" notification whenever a program sets the clipboard, including through tmux with OSC 52. Emacs does that for every kill, and with Evil every y, d, x, and c is a kill, so the notifications pile up. WezTerm copied silently, so turn off just this notification and keep the one for reloading the config.

🔗

1.8 Keybindings

On Linux, Ghostty binds ctrl+shift+j by default to write the screen's contents to a file and paste the file's path. Ghostty handles the key itself, so programs in the terminal never see it, and Emacs's binding of C-S-j to swap windows silently does nothing. C-S-k, which swaps in the other direction, still works because Ghostty doesn't bind ctrl+shift+k. WezTerm had no such binding, so this only came up when we switched terminals.

ctrl+shift+j isn't the only such key. On Linux, Ghostty binds 12 other ctrl+shift+<letter> chords by default, for copying and pasting, splits, tabs, search, and so on, and each one hides that chord from Emacs and tmux in the same way. So move all of them to Super, with the same letters and the same actions. Super is free for this on Linux because xmonad uses Hyper as its modifier. On the Mac, Ghostty doesn't bind these ctrl+shift chords, so unbinding them does nothing there. Ghostty calls the Mac's Command key super, so on the Mac these bindings are on Command, where most of them already are by default, such as cmd+c for copying.

Reloading the config gets the same treatment, moving from ctrl+shift+, to super+,. On the Mac, this replaces Ghostty's default cmd+,, which opens the config file. Reloading is the one we use, and the Mac's default reload key, cmd+shift+,, still works.

The rest of Ghostty's ctrl+shift chords use keys other than letters: Enter to zoom a split, Tab and the left and right arrows to switch tabs, and Page Up and Page Down to jump between shell prompts. There is also ctrl+alt+shift+j, which writes the screen to a file and opens it. That one shadows a C-M-S- chord, the same kind of chord as our tmux bindings. For these, replace only ctrl with super and keep shift. Without shift, they would take over Mac defaults that we want to keep: cmd+left and cmd+right move to the start and end of the line, and cmd+page_up and cmd+page_down scroll. Ghostty's super+ctrl+shift chords (resizing splits, and super+ctrl+shift+j for copying the screen file's path) already use Super, so they stay as they are.

The keys that change the font size don't use shift, but on Linux they still take ctrl chords (ctrl+=, ctrl++, ctrl+-, and ctrl+0) away from Emacs. Move them to Super as well, which makes them the same as the Mac's defaults.

On Linux, ctrl+, opens Ghostty's config file in the default app for text files, which for us is a whole new Emacs window, so Emacs inside the terminal never gets C-,. Its natural Super key, super+,, now reloads the config, and super+shift+, is the Mac's default for reloading. So just unbind ctrl+, and leave opening the config to the command palette or to our editor.

On Linux, Ghostty also takes some ctrl and alt chords without shift: ctrl+tab, ctrl+page_up, and ctrl+page_down switch tabs, alt+1 through alt+9 go to a tab, ctrl+enter toggles fullscreen, ctrl+alt with an arrow moves between splits, ctrl+insert copies, and alt+f4 closes the window. So cat -v shows nothing at all for C-TAB, and Emacs never sees M-1 through M-9 as digit arguments. Unbind all of them. Ghostty binds both the key and the physical key forms of the digits (alt+1 and alt+digit_1), so unbind both.

Give the digits and splits Super keys, which are the Mac's defaults: super+1 through super+9 and super+alt with an arrow. We don't need the others on Super. Tab switching is already on super+shift with Tab and the arrows above, copying is on super+c, and xmonad toggles fullscreen and closes windows.

1.9 Keys that Ghostty can't encode unambiguously

tmux asks Ghostty for modifyOtherKeys mode 2, so that extended keys reach Emacs. But even in that mode, Ghostty 1.3.1 sends a few chords as the same bytes as other keys:

  • ctrl+backspace is ^H, which tmux and Emacs read as C-h. Its key table has an extended encoding for every Backspace chord except Ctrl alone.

  • ctrl+shift+space is NUL, the same as ctrl+space, and ctrl+alt+shift+space is ESC NUL, the same as ctrl+alt+space. Before Ghostty looks at modifyOtherKeys, it turns any Ctrl chord whose key isn't a letter into a control character, and it drops Shift to do so.

So send the CSI u sequences for these chords ourselves, as our WezTerm configuration did. tmux reads them and passes them on to Emacs as they are. To a shell, which doesn't ask for modifyOtherKeys mode 2, tmux sends the two Space chords as NUL and ESC NUL again, but it sends ctrl+backspace on as \e[127;5u, so zsh binds that sequence.

Without this, ctrl+backspace in zsh was worse than useless: zsh binds ^h to go back to the previous directory.

We don't do the same for ctrl+[, which Ghostty sends as ESC. That's the traditional meaning of C-[, and Evil relies on it to leave insert state.

1.10 Open URL

super+shift+y opens a URL on the screen, as in WezTerm. tmux does the work, but tmux can't see Super, so send it \e[9001~, which tmux binds through its user-keys option. No real key sends that sequence.

🔗
open-url

Used by Anonymous Block Cell 2.

Other metadata key/value pairs:

  • __block_type = src

  • __src_language = conf

keybind = super+shift+y=text:\x1b[9001~
