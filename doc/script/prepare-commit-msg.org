#+title: Git commit message hook

#+lilac_maxHeadingLevel: 4

* Description

Prepare Git commit messages to be Org-mode friendly.

* Motivation

Since 6f8215a6 (git: personal: make commits verbose, 2017-01-19) we've had
verbose commit messages where the diff of what's staged is shown in the
(ignored) commit message footer area.

We started using Org-mode as the major mode for commit message buffers in
65800d22 (emacs commit message buffers: use smarter paragraph filling,
2024-08-03).

The problem is that the diff area that's displayed by 6f8215a6 can slow down Org
mode because it will get confused by the diff text (perhaps it thinks line
additions and deletions which begin with =+= and =-=, create plain list items).

The solution is to just wrap the diff text inside a source code block, so that
it gets ignored (for purposes of list parsing) by Org mode.

Even inside a source block, a very large diff still slows Emacs to a crawl when
it creates the commit message buffer, so we also [[truncate-diff][truncate]] the diff. The diff is
only there for us to read; Git ignores everything below the scissors line, so
cutting it down never changes what gets committed.

* Implementation

** Clojure (Babashka)

The tricky part is figuring out how to add a line to the middle of the file
somewhere. For that we have to read the file into memory first, construct the
new file contents in memory, then write it back out.

#+header: :tangle script/git/hooks/prepare_commit_msg.bb
#+begin_src clojure

<<main>>

*** Truncate large diffs

Two things make a diff slow for Emacs: sheer volume, and very long lines (which
are hard on redisplay and font-locking). So we limit both. A file whose diff is
longer than ~max-file-lines~ keeps only its first ~head-lines~ and last
~tail-lines~ lines, with a marker line in between saying how many were left
out. Keeping both ends shows where the changes start and how they end, which is
usually enough to jog our memory when writing the message. A line longer than
~max-line-chars~ is cut off with a note of how many characters were dropped.
The thresholds are rough guesses at where things start to feel slow, so they
are named here to make them easy to tune.

#+name: truncate-diff
#+begin_src clojure
(def max-file-lines 300)
(def head-lines 100)
(def tail-lines 50)
(def max-line-chars 500)

(defn truncate-line
  [line]
  (if (> (count line) max-line-chars)
    (str (subs line 0 max-line-chars)
         " [... " (- (count line) max-line-chars) " more characters]")
    line))

(defn truncate-file-diff
  [s]
  (let [lines (str/split s #"\n" -1)
        n (count lines)]
    (->> (if (> n max-file-lines)
           (concat (take head-lines lines)
                   [(str "[... " (- n head-lines tail-lines) " lines omitted ...]")]
                   (take-last tail-lines lines))
           lines)
         (map truncate-line)
         (str/join "\n"))))

(defn truncate-diff
  [s]
  (->> (str/split s #"(?m)^(?=diff --git )")
       (map truncate-file-diff)
       str/join))
#+end_src

~truncate-diff~ splits the diff into one piece per file, right before each
~diff --git~ line. The split is zero-width (a lookahead), so no text is lost
and joining the pieces back together restores the original. Within a piece we
split on newlines with a limit of ~-1~, which keeps the trailing empty string
after the final newline, so that a diff we don't truncate comes back exactly
as it was.

*** Wrap diff portion

This has two parts: wrapping the diff in a string, and doing that to a file.

#+name: wrap-diff-portion
#+begin_src clojure
<<wrap-diff>>
<<wrap-diff-file>>
#+end_src

The hard part is locating the "diff" string in the file. We can let =str/split= do
most of the heavy lifting. Instead of reading the file and splitting
line-by-line, we can slurp it into memory and then use =str/index-of= to find
where the first "diff " string occurs in the file. Then we can extract the
substrings before and after this bit.

#+name: wrap-diff
#+begin_src clojure
(def pats
  ["#\ndiff "
   "# Everything below it will be ignored.\ndiff "])

(defn- search-pat
  [s pat]
  [(str/index-of s pat)
   (str/index-of pat "diff")])

(defn wrap-diff
  [s]
  (if-let [[idx offset] (->> pats
                             (map #(search-pat s %))
                             (some (fn [[idx _ :as tup]]
                                     (when (some? idx) tup))))]
    (let [before (subs s 0 (+ offset idx))
          after (truncate-diff (subs s (+ offset idx)))
          new-parts [before
                     "#+begin_src diff\n"
                     after
                     "#+end_src\n"]]
      (str/join new-parts))
    s))
#+end_src

We have to shift =idx= by an offset when taking the substring, because we want to
skip past the =#...\n= bits just before the ="diff"=. Note that we look for two
different patterns (see =pats=) and use whichever one works.

We use =if-let= in case the input string doesn't have the ="\ndiff "= substring in
it, in which case we abort doing any mutations to it and return the original
string unmodified.

Only the diff part (=after=) goes through [[truncate-diff][~truncate-diff~]], so the commit
message itself and Git's comments above the diff are never touched.

Now we can read the file, invoke our wrapper, and then write back out the
result. We use =slurp= and =spit= for this.

#+name: wrap-diff-file
#+begin_src clojure
(defn wrap-diff-portion
  [file]
  (->> (slurp file)
       wrap-diff
       (spit file)))
#+end_src

The tests for [[truncate-diff][~truncate-diff~]] build their inputs from the thresholds, so they
keep working if we tune them. A small diff must come back unchanged. A long
line keeps exactly ~max-line-chars~ characters. A long file keeps its head and
tail around the marker, while a small file after it in the same diff is left
alone.

#+name: tests-truncate
#+begin_src clojure
(deftest truncate-diff
  (is (= "" (sut/truncate-diff "")))
  (is (= commit-msg-text (sut/truncate-diff commit-msg-text)))
  (let [extra 7
        line (str/join (repeat (+ sut/max-line-chars extra) "x"))]
    (is (= (str (subs line 0 sut/max-line-chars)
                " [... " extra " more characters]\n")
           (sut/truncate-diff (str line "\n")))))
  (let [n (* 2 sut/max-file-lines)
        big (str "diff --git a/big b/big\n"
                 (str/join "\n" (map #(str "+" %) (range n)))
                 "\n")
        small "diff --git a/small b/small\n+x\n"
        out (str/split-lines (sut/truncate-diff (str big small)))
        omitted (- (+ n 2) sut/head-lines sut/tail-lines)]
    (is (= "diff --git a/big b/big" (first out)))
    (is (= (str "[... " omitted " lines omitted ...]")
           (nth out sut/head-lines)))
    (is (= (str "+" (dec n)) (nth out (+ sut/head-lines sut/tail-lines -1))))
    (is (= ["diff --git a/small b/small" "+x"]
           (take-last 2 out)))))
#+end_src

*** Main

Git will pass in the path of the =COMMIT_MSG= file as the first argument; this
file is what we want to modify. We ignore other arguments passed to us (=rst=).

#+name: main
#+begin_src clojure
(defn -main [& [file & rst]]
  (wrap-diff-portion file))
(when (= *file* (System/getProperty "babashka.file"))
  (apply -main *command-line-args*))
#+end_src

The =-main= function just calls =wrap-diff-portion= with =file=. The
=System/getProperty= stuff is from [[https://github.com/babashka/book/blame/eea70f8cf5185eb65e87066ddaf36c66fe22bceb/src/recipes.adoc#L44-L73][the Babashka book]] to make it nicer to interact
with the file in the CLI and also the REPL.

*** Arguments

Git will call our script with the path of the special ~COMMIT_MSG~ file as the
first argument.

#+name: arguments
#+begin_src sh
COMMIT_MSG_FILE=$1
#+end_src

*** Source code block wrapper

#+name: wrap-diff-with-source-code-block
#+begin_src sh
<<sed-begin-src>>
<<echo-end-src>>
#+end_src

Wrapping the diff part just means adding

#+begin_src org
,#+begin_src diff
#+end_src

and

#+begin_src org
,#+end_src
#+end_src

around the diff portion.

**** Add =#+begin_src diff=

The trick here is to tell =sed= (GNU sed) [fn:gnu-sed] to only concern itself with
the area of the file where the =diff= word appears the first time. This is because
the diff could have multiple hunks in it (each with its own =diff ...= section).
That's what the =0,/^diff/= means below:

#+name: sed-begin-src
#+begin_src sh
sed -i '0,/^diff/{s/^diff /#+begin_src diff\ndiff /}' "${COMMIT_MSG_FILE}"
#+end_src

We use =-i= to edit the file in-place.

**** Add =#+end_src=

Adding the =#+end_src= is easy because it just has to be at the end of the file.
We use shell redirection =>>= (for appending) to do this.

#+name: echo-end-src
#+begin_src sh
echo '#+end_src' >> "${COMMIT_MSG_FILE}"
#+end_src
