* less

The ~lesskey~ [[id:bbe0ff18-1b29-4f04-b2a6-5f3d7b003eb5][Makefile]] rule links this to ~\~/.lesskey~ and runs ~lesskey~ on it. This
sets up the backspace and delete keys, along with the default options in ~LESS~,
which the comments below explain.

#+name: lesskey
#+header: :tangle lesskey/cfg
#+begin_src conf
#command

# map backspace to back-screen
      back-screen

#line-edit
\e[3~          delete

#env

# -F: exit less if everything can be displayed in one screen
#
# -i: make lower-case-only searches case insensitive (mixed-case searches are
# automatically case-sensitive!)
#
# -M: verbose status bar to show location information
#
# -R: make 'git diff' more compliant with highly customized LESS_TERMCAP options
#
# -X: try not to clear the screen
#
# --tabs=4: set tab stop to 4 spaces (default 8)
LESS = -FiMRX --tabs=4
#+end_src

* MPD

MPD plays our music both locally through PulseAudio and as an HTTP stream for other
machines to listen to.

#+name: mpd-conf
#+header: :tangle mpd/mpd.conf
#+begin_src conf
# Adapted from
# https://raw.githubusercontent.com/MusicPlayerDaemon/MPD/master/doc/mpdconf.example.

music_directory     "~/Music"
# Automatically prune new/deleted files in the music_directory.
auto_update         "yes"

# Allow saving playlists from vimpc.
playlist_directory  "~/Music/playlists"

# Local output.
audio_output {
    type            "pulse"
    name            "pulseaudio-output"
}

# Streaming output. You have to first control MPD via an SSH session. If you
# did a toplevel `bind_to_address` and `port` configuration, you could control
# MPD playback (think of it as a remote control) via the IP and port. However
# we already have SSH access to this machine so there is no point in
# configuring that. As soon as the playback *begins*, the IP and port here
# become active clients can then connect to it.
#
# So the process is:
#   (1) start MPD playback via SSH
#   (2) run `mpv http://192.168.1.4:8030` to start listening to it from the client
#
audio_output {
    type            "httpd"
    name            "http-output"
    encoder         "opus"
    port            "8010"
    bind_to_address "192.168.1.4"
    bitrate         "96000"
    format          "48000:16:2"
    always_on       "yes"
    tags            "yes"
}

# Enable replay gain.
replaygain          "track"
#+end_src

* SSH

The ~ssh~ [[id:bbe0ff18-1b29-4f04-b2a6-5f3d7b003eb5][Makefile]] rule links this to ~\~/.ssh/config~. This keeps connections alive,
forwards our agent to machines on the home network, and picks the key to use for
GitHub and SourceHut.

#+name: ssh-config
#+header: :tangle ssh/config.home.conf
#+begin_src conf
Host *
    ServerAliveInterval 15
Host 192.168.1.*
    ForwardAgent yes
Host github.com
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_rsa_github
Host git.sr.ht
    HostName git.sr.ht
    User git
    IdentityFile ~/.ssh/id_rsa_github
Host *.builds.sr.ht
    User builds
    IdentityFile ~/.ssh/id_rsa_github
#+end_src

* terminfo

This defines the ~xterm-24bit~ terminal type, for 24-bit color and italics. The
~terminfo~ [[id:bbe0ff18-1b29-4f04-b2a6-5f3d7b003eb5][Makefile]] rule compiles it with ~tic~, and [[id:4ef05c5a-117f-4b9c-8bee-dc1eaae8efc7::zshenv][~.zshenv~]] sets this as our ~TERM~
on ~w0~.

#+name: xterm-24bit
#+header: :tangle terminfo/xterm-24bit.terminfo
#+begin_src conf
xterm-24bit|xterm with 24-bit direct color mode,
   use=xterm-256color,
   sitm=\E[3m,
   ritm=\E[23m,
   setb24=\E[48;2;%p1%{65536}%/%d;%p1%{256}%/%{255}%&%d;%p1%{255}%&%dm,
   setf24=\E[38;2;%p1%{65536}%/%d;%p1%{256}%/%{255}%&%d;%p1%{255}%&%dm,
#+end_src

* vimpc

Vim-like key bindings for ~vimpc~, the client that we use for [[mpd-conf][MPD]].

#+name: vimpcrc
#+header: :tangle vimpc/.vimpcrc
#+begin_src vim
set windows playlist,browse,library,lists
set window playlist

" Navigate up/down any window quickly.
map <Space> 10j
map <BS> 10k

" Make tab navigation reasonable. Unfortunately <C-h> cannot be bound as it
" conflicts with <BS>. So we have to use the Alt key instead.
map <A-h> :tabprevious<Enter>
map <A-l> :tabnext<Enter>

" Skip forward/backward 5 seconds.
map h :seek- 5<Enter>
map l :seek+ 5<Enter>

" Change songs.
map H :previous<Enter>
map L :next<Enter>

map p :pause<Enter>

" <C-c> already exits vimpc.
map <C-d> :qa<Enter>

" Go to current song.
map c f

" Go to random song.
map r %

" Increase volume.
map = +
#+end_src
