#+title: Ghostty

[[https://ghostty.org][Ghostty]] is the terminal we're trying out as a replacement for [[id:1d490bfa-6d4a-4b0e-beac-d3e37fbb21a5][WezTerm]]. We
install it with Nix on both [[id:82cbef73-61b9-43e7-9df6-7b2771000733::pkgs:ghostty-nixos][NixOS]] and [[id:82cbef73-61b9-43e7-9df6-7b2771000733::pkgs:ghostty-darwin][Mac]]. Its configuration is a flat
list of ~key = value~ lines.

* Configuration

#+header: :tangle ghostty/config
#+begin_src conf
<<option-as-alt>>
<<cursor>>
<<font>>
<<window>>
<<gtk-titlebar>>
<<colors>>
<<confirm-close>>
<<keybindings>>
#+end_src

The ~ghostty~ [[Makefile-ghostty][Makefile rule]] links only the ~config~ file, not the whole
directory, because Ghostty is free to write other files into
~\~/.config/ghostty~.

#+name: Makefile-ghostty
#+begin_src makefile
ghostty:
	mkdir -p ${H}/.config/ghostty
	ln -fs ${C}/ghostty/config ${H}/.config/ghostty/config
#+end_src

** Option as Alt

By default, Ghostty on Mac treats Option the way macOS does: as a key for
typing accented and other special characters. Then a chord like ~C-M-S-e~ (our
tmux binding to [[id:9170fae9-85de-4fd8-96fb-f3d3d2215f94::keybindings-pane-create][split a pane]]) reaches tmux as some special character instead of
a Meta chord, and none of our ~C-M-~ tmux bindings, or ~M-~ bindings anywhere
else, work. WezTerm doesn't have this problem because it treats the left Option
key as Alt by default.

So treat the left Option key as Alt too. The right Option key still types
special characters, for the rare times we want them.

#+name: option-as-alt
#+begin_src conf
macos-option-as-alt = left
#+end_src

** Cursor

Don't blink the cursor, just as in [[id:1d490bfa-6d4a-4b0e-beac-d3e37fbb21a5::cursor][WezTerm]]. Unlike WezTerm's setting, this is only the
default: programs can still turn blinking on with escape sequences. Terminal
Emacs does that unless we [[id:100011e3-ba36-4078-975e-6136d25e60cc::tty-cursor-blink][tell it not to]].

#+name: cursor
#+begin_src conf
cursor-style-blink = false
#+end_src

** Font

As in [[id:1d490bfa-6d4a-4b0e-beac-d3e37fbb21a5::font][WezTerm]], turn on Commit Mono's ~cv06~ feature, which gives the 6 and 9
numerals a straight tail instead of a curved one.

#+name: font
#+begin_src conf
font-family = "CommitMono"
font-size = 17
font-feature = cv06
#+end_src

** Window

Open windows at the same size as [[id:1d490bfa-6d4a-4b0e-beac-d3e37fbb21a5::window-size][WezTerm's]], in cells, and with the same
[[id:1d490bfa-6d4a-4b0e-beac-d3e37fbb21a5::window-padding][padding]]: a little on the left, so that text doesn't touch the window's edge,
and none elsewhere. ~window-padding-x~ takes the left and right padding as a
pair.

#+name: window
#+begin_src conf
window-width = 163
window-height = 102
window-padding-x = 4,0
window-padding-y = 0
#+end_src

On Linux, Ghostty draws its own GTK title bar, with a menu and tab buttons,
across the top of every window. Under [[id:68954bd6-189f-48ab-9ded-8b6cbe3a0952][xmonad]] this is just wasted space, because
xmonad manages the windows and we keep tabs in tmux, which is also why we
[[id:1d490bfa-6d4a-4b0e-beac-d3e37fbb21a5::disable-tab-bar][disable WezTerm's tab bar]]. So turn it off. We use ~gtk-titlebar~ rather than
~window-decoration = none~, because ~gtk-titlebar~ does nothing on Mac, where
~window-decoration = none~ would also remove the window's native border and
rounded corners.

#+name: gtk-titlebar
#+begin_src conf
gtk-titlebar = false
#+end_src

** Colors

Use our [[id:205ec9d4-2e2f-46f7-a1aa-c3105e1ba491::theme-pasteldark][PastelDark]] theme, the same colors as in [[id:1d490bfa-6d4a-4b0e-beac-d3e37fbb21a5::colors][WezTerm]]. The theme has to be
in the config, not just applied by the shell, because Zsh assumes that the
terminal starts out with PastelDark (it sets ~TERM_COLOR_THEME~ to it without
sending any colors), so that [[id:fd0afd0c-d608-4ad5-83ff-6a080a62bc66::func-color-cycle][~color_cycle~]] knows where to start.

As in WezTerm, bright black (palette entry 8) is ~#99999f~ instead of the
theme's ~#343c48~. The theme's value is the background color, so programs that
draw text in bright black (such as ~jj~) would leave what look like empty spots.

The selection colors also come from WezTerm, because the theme doesn't define
any.

background = #343c48
foreground = #e5e7ea
cursor-color = #ffffff
cursor-text = #000000
selection-background = #fffacd
selection-foreground = #000000

** Closing windows

By default, Ghostty asks for confirmation before closing a window (or tab or
split) whose shell is running another program. Our shell [[id:9b76d360-8483-4449-b3a5-6c3678defc58][replaces itself with
tmux]], so every window counts as busy and Ghostty asks every time. But closing
the window only detaches from tmux, and the session lives on, so nothing is lost
and the question is just noise. So close without asking.

#+name: confirm-close
#+begin_src conf
confirm-close-surface = false
#+end_src

** Keybindings

On Linux, Ghostty binds ~ctrl+shift+j~ by default to write the screen's
contents to a file and paste the file's path. Ghostty handles the key itself, so
programs in the terminal never see it, and Emacs's binding of ~C-S-j~ to
[[id:100011e3-ba36-4078-975e-6136d25e60cc::window-navigation][swap windows]] silently does nothing. ~C-S-k~, which swaps in the other
direction, still works because Ghostty doesn't bind ~ctrl+shift+k~. WezTerm has
no such binding, so this only came up when we switched terminals.

~ctrl+shift+j~ isn't the only such key. On Linux, Ghostty binds 12 other
~ctrl+shift+<letter>~ chords by default, for copying and pasting, splits, tabs,
search, and so on, and each one hides that chord from Emacs and tmux in the same
way. So move all of them to Super, with the same letters and the same actions.
Super is free for this on Linux because [[id:68954bd6-189f-48ab-9ded-8b6cbe3a0952][xmonad]] uses Hyper as its modifier. On
the Mac, Ghostty doesn't bind these ~ctrl+shift~ chords, so unbinding them does
nothing there. Ghostty calls the Mac's Command key ~super~, so on the Mac these
bindings are on Command, where most of them already are by default, such as
~cmd+c~ for copying.

Reloading the config gets the same treatment, moving from ~ctrl+shift+,~ to
~super+,~. On the Mac, this replaces Ghostty's default ~cmd+,~, which opens the
config file. Reloading is the one we use, and the Mac's default reload key,
~cmd+shift+,~, still works.

The rest of Ghostty's ~ctrl+shift~ chords use keys other than letters: Enter to
zoom a split, Tab and the left and right arrows to switch tabs, and Page Up and
Page Down to jump between shell prompts. There is also ~ctrl+alt+shift+j~, which
writes the screen to a file and opens it. That one shadows a ~C-M-S-~ chord, the
same kind of chord as our tmux bindings. For these, replace only ~ctrl~ with
~super~ and keep ~shift~. Without ~shift~, they would take over Mac defaults that
we want to keep: ~cmd+left~ and ~cmd+right~ move to the start and end of the
line, and ~cmd+page_up~ and ~cmd+page_down~ scroll. Ghostty's ~super+ctrl+shift~
chords (resizing splits, and ~super+ctrl+shift+j~ for copying the screen file's
path) already use Super, so they stay as they are.

The keys that change the font size don't use ~shift~, but on Linux they still
take ~ctrl~ chords (~ctrl+=~, ~ctrl++~, ~ctrl+-~, and ~ctrl+0~) away from Emacs.
Move them to Super as well, which makes them the same as the Mac's defaults.

On Linux, ~ctrl+,~ opens Ghostty's config file in the default app for text
files, which for us is a whole new Emacs window, so Emacs inside the terminal
never gets ~C-,~. Its natural Super key, ~super+,~, now reloads the config, and
~super+shift+,~ is the Mac's default for reloading. So just unbind ~ctrl+,~ and
leave opening the config to the command palette or to our editor.

On Linux, Ghostty also takes some ~ctrl~ and ~alt~ chords without ~shift~:
~ctrl+tab~, ~ctrl+page_up~, and ~ctrl+page_down~ switch tabs, ~alt+1~ through
~alt+9~ go to a tab, ~ctrl+enter~ toggles fullscreen, ~ctrl+alt~ with an arrow
moves between splits, ~ctrl+insert~ copies, and ~alt+f4~ closes the window. So
~cat -v~ shows nothing at all for ~C-TAB~, and Emacs never sees ~M-1~ through
~M-9~ as digit arguments. Unbind all of them. Ghostty binds both the key and the
physical key forms of the digits (~alt+1~ and ~alt+digit_1~), so unbind both.

Give the digits and splits Super keys, which are the Mac's defaults: ~super+1~
through ~super+9~ and ~super+alt~ with an arrow. We don't need the others on
Super. Tab switching is already on ~super+shift~ with Tab and the arrows above,
copying is on ~super+c~, and xmonad toggles fullscreen and closes windows.
