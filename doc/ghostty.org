#+title: Ghostty

[[https://ghostty.org][Ghostty]] is the terminal we're trying out on Mac as a replacement for
[[id:1d490bfa-6d4a-4b0e-beac-d3e37fbb21a5][WezTerm]]. Its configuration is a flat list of ~key = value~ lines.

* Configuration

#+header: :tangle ghostty/config
#+begin_src conf
<<option-as-alt>>
<<cursor>>
<<font>>
<<window>>
<<colors>>
#+end_src

The ~ghostty~ [[Makefile-ghostty][Makefile rule]] links only the ~config~ file, not the whole
directory, because Ghostty is free to write other files into
~\~/.config/ghostty~.

#+name: Makefile-ghostty
#+begin_src makefile
ghostty:
	mkdir -p ${H}/.config/ghostty
	ln -fs ${C}/ghostty/config ${H}/.config/ghostty/config
#+end_src

** Option as Alt

By default, Ghostty on Mac treats Option the way macOS does: as a key for
typing accented and other special characters. Then a chord like ~C-M-S-e~ (our
tmux binding to [[id:9170fae9-85de-4fd8-96fb-f3d3d2215f94::keybindings-pane-create][split a pane]]) reaches tmux as some special character instead of
a Meta chord, and none of our ~C-M-~ tmux bindings, or ~M-~ bindings anywhere
else, work. WezTerm doesn't have this problem because it treats the left Option
key as Alt by default.

So treat the left Option key as Alt too. The right Option key still types
special characters, for the rare times we want them.

#+name: option-as-alt
#+begin_src conf
macos-option-as-alt = left
#+end_src

** Cursor

Don't blink the cursor, just as in [[id:1d490bfa-6d4a-4b0e-beac-d3e37fbb21a5::cursor][WezTerm]]. Unlike WezTerm's setting, this is only the
default: programs can still turn blinking on with escape sequences. Terminal
Emacs does that unless we [[id:100011e3-ba36-4078-975e-6136d25e60cc::tty-cursor-blink][tell it not to]].

#+name: cursor
#+begin_src conf
cursor-style-blink = false
#+end_src

** Font

As in [[id:1d490bfa-6d4a-4b0e-beac-d3e37fbb21a5::font][WezTerm]], turn on Commit Mono's ~cv06~ feature, which gives the 6 and 9
numerals a straight tail instead of a curved one.

#+name: font
#+begin_src conf
font-family = "CommitMono"
font-size = 17
font-feature = cv06
#+end_src

** Window

Open windows at the same size as [[id:1d490bfa-6d4a-4b0e-beac-d3e37fbb21a5::window-size][WezTerm's]], in cells, and with the same
[[id:1d490bfa-6d4a-4b0e-beac-d3e37fbb21a5::window-padding][padding]]: a little on the left, so that text doesn't touch the window's edge,
and none elsewhere. ~window-padding-x~ takes the left and right padding as a
pair.

#+name: window
#+begin_src conf
window-width = 163
window-height = 102
window-padding-x = 4,0
window-padding-y = 0
#+end_src

** Colors

Use our [[id:205ec9d4-2e2f-46f7-a1aa-c3105e1ba491::theme-pasteldark][PastelDark]] theme, the same colors as in [[id:1d490bfa-6d4a-4b0e-beac-d3e37fbb21a5::colors][WezTerm]]. The theme has to be
in the config, not just applied by the shell, because Zsh assumes that the
terminal starts out with PastelDark (it sets ~TERM_COLOR_THEME~ to it without
sending any colors), so that [[id:fd0afd0c-d608-4ad5-83ff-6a080a62bc66::func-color-cycle][~color_cycle~]] knows where to start.

As in WezTerm, bright black (palette entry 8) is ~#99999f~ instead of the
theme's ~#343c48~. The theme's value is the background color, so programs that
draw text in bright black (such as ~jj~) would leave what look like empty spots.

The selection colors also come from WezTerm, because the theme doesn't define
any.

#+name: colors
#+begin_src conf
background = #343c48
foreground = #e5e7ea
cursor-color = #ffffff
cursor-text = #000000
selection-background = #fffacd
selection-foreground = #000000
palette = 0=#22222f
palette = 1=#e49f9f
palette = 2=#91e380
palette = 3=#eae47c
palette = 4=#7cacd3
palette = 5=#df9494
palette = 6=#8cdbd8
palette = 7=#e5e7ea
palette = 8=#99999f
palette = 9=#e5bfbf
palette = 10=#afe0a1
palette = 11=#f2fb9e
palette = 12=#95add1
palette = 13=#f2b0b0
palette = 14=#b4f0f0
palette = 15=#ffffff
#+end_src
