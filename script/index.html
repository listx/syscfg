3 Test runner

This script just imports all Clojure test files and then runs them.

🔗
🎯 script/test-runner.clj

Other metadata key/value pairs:

  • __anon_block_number = 1

  • __block_type = src

  • __src_language = clojure

  • shebang = #!/usr/bin/env bb

(require '[clojure.test :refer [run-tests]]
         '[babashka.classpath :refer [add-classpath]])

(add-classpath ".")

(def namespaces
  ["find-long-lines"
   "prepare-commit-msg"])

(doseq [namespace namespaces]
  (let [test-namespace (symbol (str namespace "-test"))
        _ (require test-namespace)
        {:keys [fail error]} (run-tests test-namespace)]
    (when (pos? (+ fail error))
      (System/exit 1))))
